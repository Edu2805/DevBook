# DevBook

Uma rede social simples para aprendizado em **Golang**.

## Sobre o projeto

O DevBook é um projeto educacional desenvolvido para praticar a criação de aplicações web e APIs usando Go. Usuários podem criar publicações e interagir com conteúdos compartilhados pela comunidade.

## Funcionalidades

- Cadastro e login de usuários
- Criação, edição e exclusão de publicações
- Curtidas e comentários
- Feed de publicações
- Perfil de usuário

## Tecnologias

- Go (Golang)
- API REST
- HTML, CSS e JavaScript
- Banco de dados relacional

## Como executar

```bash
go mod tidy
go run .
```

## Objetivo

Aprender, na prática, conceitos de desenvolvimento web e construção de APIs com Go.
